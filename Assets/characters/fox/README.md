# Fox Buddy Asset

Source: KhronosGroup glTF Sample Models, `2.0/Fox/glTF-Binary/Fox.glb`.

License notes from the upstream model README:
- Low poly fox mesh by PixelMannen: CC0.
- Rigging and animation by @tomkranis on Sketchfab: CC-BY 4.0.
- glTF conversion by @AsoboStudio and @scurest.

This project currently renders the GLB mesh as a physics toy object and applies procedural buddy motion in the renderer. The original GLB still contains the rig and animation clips for a future skeletal animation pass.
